## Task

Explain the 缠论 concept: $ARGUMENTS

## Explanation Format

1. **定义**: 缠中说禅原意，精确定义
2. **物理含义**: 对应的多空力量含义
3. **图解**: ASCII art 在价格图上展示
4. **实例**: 具体数字例子（优先用用户最近分析过的标的数据）
5. **对比**: 与相关概念的区别（如 趋势背驰 vs 盘整背驰）
6. **常见误区**: 初学者容易犯的错误

## Core Concepts

### K线合并: 包含关系处理，合并方向取决于之前的趋势方向
### 分型: 顶分型（中间K线最高）/ 底分型（中间K线最低）
### 笔: 连接相邻顶底分型，至少5根合并K线
### 中枢: 至少3笔重叠区间 [max(低点们), min(高点们)]
### 趋势: 两个同向中枢 → 趋势；单中枢 → 盘整
### 背驰: 同向笔的MACD面积比较，价格创新极值但面积缩小
### 盘整背驰: DIF未过零轴，中枢内部波动衰竭（弱信号）
### 趋势背驰: DIF过零轴后面积缩小，整个趋势动能衰竭（强信号）
### 1买/1卖: 背驰触发
### 2买/2卖: 回调/反弹不创新极值
### 3买/3卖: 回调/反弹不进入中枢
### MACD面积: DIF与DEA围成的面积 = 一段走势的总动能
